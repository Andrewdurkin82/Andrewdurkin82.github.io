Sho Control

A browser-based control layer built around an existing digital-signage system so the people operating it could manage content without fighting the underlying software.

Make the existing system easier to use.

The goal was not to replace the signage platform or hardware. It was to put a cleaner operator experience in front of it. Sho Control was built around the real workflow: preview what is playing, manage what comes next, reuse slides, upload new content, and schedule material without digging through a clumsy control interface.

The project evolved through repeated use on the actual display setup. Features and layout changed based on what made the system faster and clearer for the people using it, including queue controls, reusable content, scheduling, and a simplified screen built around the tasks that actually mattered.

It also reduced an access-control risk in the underlying platform. In the native Sho Stick software, a logged-in user can access every stick in the account and can potentially change or erase content on the wrong device. Sho Control gives day-to-day users a narrower interface for the work they actually need to do, which means fewer people need direct access to the full administrative software.
