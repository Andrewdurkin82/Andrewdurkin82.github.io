How I work

Start with the system, not the buzzword.

I’m interested in AI because it can change how work gets done, not because every problem needs a model attached to it. Sometimes the right answer is retrieval architecture. Sometimes it is a better ERP workflow, a CRM, a queue, or a different decision point.

The common thread is systems thinking: understand the people, incentives, information, bottlenecks, and failure states first. Then build the smallest useful thing that changes the outcome.

AI-assisted application design
Workflow and process analysis
LLM context and retrieval systems
ERP and operational automation
CRM and case-management design
Evaluation and failure analysis

Technology matters. Whether it actually improves the work matters more.

This portfolio documents the systems, experiments, operational redesigns, and prototypes behind that approach.
